# 🎙️ Speech to Text Web App

This is a collaborative speech-to-text web app with:

- Real-time transcription using Web Speech API
- Language selection
- Voice command support
- Save transcript to file (via backend)
- Mic volume indicator

## 🧩 Tech Stack

- Frontend: HTML, CSS, JavaScript (Vanilla)
- Backend: Node.js + Express
- Collaboration: Git + GitHub

## 🚀 How to Run

### Frontend
Open `frontend/index.html` in Chrome. Use Live Server for convenience.

### Backend
```bash
cd backend
npm install
npm start
